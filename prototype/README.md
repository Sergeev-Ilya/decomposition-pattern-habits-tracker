# Ритм — интерактивный прототип

Интерактивный UI-прототип (Vite + React + Tailwind v4). Mock-данные, без backend. Четыре страницы и три диалога из согласованной спецификации.

## Как попробовать

На странице входа нажмите **«Посмотреть демо»**. Для ручного входа: `demo@ritm.app` / `demo1234`.

В демо доступны шесть привычек с историей относительно сегодняшней даты в часовом поясе браузера. Попробуйте поставить и отменить сегодняшнюю отметку, открыть привычку, переключить месяц, изменить доступную дату, создать, отредактировать или удалить привычку. Недельное окно включает сегодня и семь предыдущих календарных дней, но не дни до создания привычки. Процент рассчитан от всех календарных дней выбранного месяца.

Регистрация создаёт пустой mock-аккаунт. Выйдите и войдите с указанными данными, чтобы увидеть пустое состояние и добавить свою привычку. Аккаунты и изменения сохраняются только в памяти открытой страницы: после перезагрузки прототип возвращается к исходным данным. Пароли не записываются в браузерное хранилище и не отправляются по сети; используйте вымышленные данные. Настоящие авторизация, постоянное хранение, серверные проверки и обработка сетевых ошибок появятся на следующих этапах.

Все начальные данные находятся в `src/data/mock.ts`. Главные маршруты: `/login`, `/register`, `/`, `/habits/:habitId?month=YYYY-MM`.

## Требования

- Node.js **≥ 20.19**

## Запуск (обязательно)

```bash
cd prototype
npm install
npm run dev
```

Откройте **только** URL из вывода Vite (обычно `http://localhost:5173`).

Если порт 5173 занят, Vite выберет следующий (5174, …) — используйте URL из stdout.

## Не делайте так

Tailwind v4 генерирует CSS **только** через Vite dev/build pipeline (`@tailwindcss/vite`).

**Не работает** (страница без стилей):

- Live Preview / «Open in Browser» на `index.html`
- Открытие `index.html` через `file://`
- Статический HTTP-сервер без Vite

## Сборка (опционально)

```bash
npm run build
npm run preview   # http://localhost:4173
```

Preview тоже требует `npm run preview`, не открывайте `dist/index.html` напрямую.

## Troubleshooting: страница без стилей

1. Запускаете из **`prototype/`**, не из корня репозитория?
2. Выполнили **`npm install`** в `prototype/`? (корневой `npm install` не ставит зависимости прототипа)
3. Открыли URL из **`npm run dev`**, а не Live Preview?
4. Проверьте цепочку Tailwind v4 (не удаляйте):
   - `vite.config.ts` — plugin `tailwindcss()` из `@tailwindcss/vite`
   - `src/main.tsx` — `import './index.css'`
   - `src/index.css` — `@import "tailwindcss"`
