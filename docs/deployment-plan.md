# Ритм — размещение и инфраструктура

Статус: **решения согласованы пользователем**: локально, без брокера сообщений, S3, CI и домена. Параметры SSH не требуются. Удалённое размещение не входит в выбранный запуск.

Для первой рабочей версии принят следующий набор:

| Решение | Согласованное значение | Основание |
|---|---|---|
| Размещение | Локально через Docker Compose | Ответ пользователя: «локально». Frontend, API и постоянное хранение запускаются в согласованном стеке. |
| SSH | Не требуется для локального запуска | При выборе удалённого сервера нужны host/IP, пользователь, имя или путь существующего ключа и каталог приложения на сервере. Содержимое приватного ключа в чат не передаётся. |
| Брокер сообщений | Не подключать | Согласованные сценарии выполняются через HTTP API; фоновые интеграции и уведомления не требуются. |
| S3-совместимое хранилище | Не подключать | В первой версии нет загрузки файлов. Данные привычек и выполнений хранятся в PostgreSQL. |
| CI | Без CI | Ответ пользователя: «без ci». Тесты и сборка выполняются в рабочем окружении. |
| Домен | Пока без домена | Для локального запуска используется localhost с портом, который будет указан при запуске. |

Удалённые подключения и публикация не выполняются. Приватные ключи и удалённые учётные данные для локального запуска не нужны.

Согласованные значения записаны в `.project/deploy.json`, `approvals.batchApprovals = true`. Архитектура, контракты и реализация завершены. Рабочее приложение запущено локально: [инструкция](run-local.md), [журнал развёртывания и сохранности](deploy-log.md).
